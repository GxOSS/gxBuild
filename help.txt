---------------------------------------------------------------
Usage    :
   gxbuild [mode] -t <type> [<switch> [<switch>...]] <out.bin>

Example  :
   gxbuild -t retail -c trinity -d 17559 -f data -p 0102...0f -o noenter

Switches:
   -v       : shows more info during build process
   -?       : shows this info

   -e <pst> : set preset for build
   -M <py>  : run python script

   -o <opt> : set gxBuild options (e.g. noenter;noinfo;nomobile;cputemp=80)
   -p <key> : 32 character CPU hex key (override, can be elsewhere)
   -b <key> : 32 character 1BL hex key (override, can be elsewhere)

   -t <type>: build type, selects ini in INI directory (retail, jtag, glitch, glitch2, glitch2m, devkit)
   -c <con> : console type, selects ini section
   -d <dir> : INI directory — contains _<type>.ini, bootloaders, flashfs/ (defaults to .)
   -f <dir> : data directory — nand dump, cpu key, smc, fcrt, keyvault (defaults to ./data)
   -m <dir> : common directory — shared bootloaders (defaults to <ini_dir>/../common)
   -i <ext> : adds _<ext> into firmware ini and patches file names
   -r <ext> : adds _<ext> into ini bl section name and patches file names

   -u <upd> : update base kernel and hypervisor with xboxupd.bin
   -x       : toggle, apply CDXeLL / RGLP patches directly, default no

   -a <name>: append addon patches or RGLP (.bin files from -d or -f dir)
   -8 <pat> : adds raw patch to NAND (format: filename.ext,offset)

   -h <form>: format of output image (system, full, xell, shadow)
   -g <dir> : output directory / location of file
   -s <file>: outputs SHA-1 of final image to <file>

   -n <cmd> : direct session access (see documentation)

legend:

[mode]      : build, extract, client, update - defaults to build if not present

<pst>       = Defined in <ini_dir>/_preset.ini: retail, 1f, JTAG (2f), glitch1, glitch2, glitch2m, glitch3

<con>       = xenon, zephyr, falcon, jasper, jaspersb, jasper256, jasper512, jasperbb, jasperbigffs,
              trinity, trinitybb, trinitybigffs, corona, corona4g, winchester, winchester4g

<dir>       = path, absolute or relative, to a directory - do not terminate with /

<key>       = 128 bit key in hexadecimal representation

<name>      = name.bin contents will be appended to hv/kernel patches

<upd>       = Xboxupd.bin to apply to Base kernel and Hypervisor (CE)

<form>      = system, full, xell, shadow - defaults to system

<out.bin>   = optional, overrides auto built output image name and location

<ext>       = using this option would cause the builder to look for _glitch_<ext>.ini instead of _glitch.ini
              and patches_jasper_<ext>.bin instead of patches_jasper.bin

<opt>       various options can be specified on the command line, see perbox sample ini for descriptions
            listed below, ALL are available to all image types
            the others can be specified but are only used for that specific image type

GXBUILD     = noenter unsafe nolog noinfo

NAND        = noecc nomobile noremap noecdremap nosecurity nosusecurity nandmu

SMC         = smcnocheck cputemp= gputemp= edramtemp= overcputemp= overgputemp= overedramtemp= cpufan= gpufan=

KV          = avregion= gameregion= dvdregion= macid= cfldv=

JTAG/GLITCH = smcnoeject smcnoblink cygnos demon xellbutton= xellbutton2= dvdkey=

JTAG only   = nodvd olddvd dualboot=

GLITCH only = patchsmc

options noted above with an = are expected to be followed with a value
specifying one of the options without an = is the same as setting TRUE in the ini
any value assigned to it will be ignored.
note that command line options take precedence over any values set in perbox ini
and that only values preceded with 0x will be interpreted as hex, MAC is the only exception

example: -o macid=00:22:48:F1:01:02;gameregion=0x00FF;nomobile
example: -o macid=00:22:48:F1:01:02 -o gameregion=0x00FF -o nomobile
example: -o macid=002248F10102 -o gameregion=255 -o nomobile

<pat>       = optional, <pat> consists of filename.ext,offset
      patches NAND image with file contents just before combining spare and finalizing ecc
      offset is the raw offset without spare data
      file will load based from the -f directory, or absolute path if drive letter is found
      add 0x to offset to specify hexadecimal, otherwise it will be read as decimal

      example: -8 myfile.bin,0x12345
      example: -8 myfile.bin,0x12345;myotherfile.bin,0x54321

DISCOVERY:
      -d <ini_dir>   Sets the INI directory. Bootloaders and flashfs are searched here first,
                     then <ini_dir>/flashfs/, then <ini_dir>/data/, then <ini_dir>/../common/

      -f <data_dir>  Sets the data directory. NAND dump, CPU key, SMC, FCRT, and Keyvault
                     are searched here. Defaults to ./data

      System updates (xboxupd.bin) are searched in <ini_dir>/ first, then <data_dir>/
