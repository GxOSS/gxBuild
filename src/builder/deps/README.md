# Builder / Deps

External dependencies used in the builder.

excrypt -> emoose's ExCrypt with minor changes (ExCrypt-gx)
mspack -> Libmspack for CAB LZX decompression
xenia -> Xenia Canary's CAB LZX implementation using mspack
xenon_bltool -> Required files from InvoxiPlayGame's xenon-bltool that have not yet been translated

liblzx -> Unused CAB LZX compression library. Will be used for recompression in the future
